# PackSmith Releases

Descargas oficiales de PackSmith para Linux, Windows y Android.

Cada Release incluye el instalador, su checksum SHA-256 y un resumen de los cambios. El código fuente, la documentación y el historial completo están en [AnonGit0/packsmith](https://github.com/AnonGit0/packsmith).

Descarga los archivos únicamente desde esta página.
